# StackPuddle CLI

Planned Go command-line interface and shared execution engine for [StackPuddle](https://github.com/TomazVidovic533/stackpuddle).

The CLI will coordinate project onboarding, configuration, module resolution, planning, environment lifecycle, and diagnostics. All supported authoring SDKs will use the same execution engine.

Shared schemas, infrastructure modules, recipes, and bundles belong to the main StackPuddle repository. Docker Compose is the first planned local runtime.

## Status

Early development. This repository currently contains only this introductory README. No installable release is available yet.
